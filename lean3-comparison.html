▼ 0. 目次・イラスト目次 重要度: 高
書き換え 車両名称の変更
コムス (COMS) → Lean3（リーン3）
書き換え 車両分類の変更
第一種原動機付自転車（四輪）/ ミニカー → 第一種普通自動車 / Class I（WLTCモード）

※Lean3は普通自動車扱いのため、運転免許証の記載も変更が必要

追加 イラスト目次の大幅変更

新規追加項目:

  • 三輪配置（前2輪・後1輪）の図解
  • Active Lean Technology の傾斜機構図
  • タッチスクリーンディスプレイの位置
  • エアコン吹き出し口
  • USB Type-C充電ポート
  • ISOFIXチャイルドシート固定点（台湾仕様のみ）
削除 COMS仕様別装備（P-COM、B-COM等）

Lean3には以下の装備は存在しないため削除:

  • トランクボックス（P-COM）
  • デリバリーボックス（B-COMデリバリー）
  • リヤデッキ（B-COMベーシック/デッキ）
▼ 1. 必ず読みましょう 重要度: 高
書き換え 車両特性の説明変更

削除: 「電気自動車独自の取扱い方」

追加: 「三輪傾斜車両（Active Lean Technology搭載）の取扱い方」

追加 Active Lean Technology の注意事項

新規追加が必要な内容:

  • 傾斜時の体の動き: カーブ時に車両が自動で傾くため、体をまっすぐに保つこと
  • 急ハンドル禁止: 傾斜システムの追従速度を超える急激な操作は避ける
  • 傾斜角度: 最大28度まで傾斜することを理解する
  • 低速時の挙動: 極低速（5km/h以下）では傾斜機能が作動しないことを周知
書き換え 乗車定員の変更
1人乗り専用 → 日本仕様: 1人乗り / 台湾仕様: 2人乗り（ISOFIXチャイルドシート対応）
書き換え タイヤ関連の変更

タイヤサイズ:

4輪とも同じサイズ → 前輪: 90/90 R14 / 後輪: 150/70 R14（サイズ異なる）

※タイヤ交換時は必ず指定サイズを使用すること

要確認 最高速度制限

情報不足: Lean3の日本仕様は60km/hが最高速度ですが、以下の情報が不明:

  • 速度リミッターの詳細仕様
  • アクセルペダルの特性（60km/h到達時の挙動）
  • 下り坂での速度超過防止機能の有無
▼ 2. 警告・使用方法ラベルの種類と貼付け位置 重要度: 中
削除 COMS固有のラベル
  • トランクボックス使用上のご注意
  • デリバリーボックス使用上のご注意
  • リヤゲート操作上のご注意
  • 仕様別ラベル全般
追加 Lean3固有のラベル

新規追加が必要なラベル:

  • Active Lean Technology 作動中: 走行中の車両傾斜に関する警告
  • タッチスクリーン操作注意: 走行中の操作制限
  • 三輪車両特有の注意: 積載制限、重心位置の警告
  • エアコン使用時の注意: 航続距離への影響
要確認 ラベルのデザインと配置

情報不足: 実際のラベル画像と貼付位置の図面が必要

▼ 3. 充電について 重要度: 高
書き換え バッテリー仕様の変更

バッテリータイプ:

鉛バッテリー（6個） → リン酸鉄リチウムイオン電池（LFP）8.1kWh

充電時間:

約6時間（満充電） → AC100V: 約7時間 / AC200V: 約5時間

航続距離:

約50km（カタログ値） → 約100km（WLTCモード Class1）
削除 バッテリー長持ちのための押し込み充電

LFPバッテリーは鉛バッテリーとは異なる管理方法のため、「押し込み充電」の概念は削除。

代わりに、リチウムイオン電池の適切な管理方法（SOC 20-80%推奨等）を追加する必要あり。

書き換え 充電表示灯の変更

削除: 充電表示灯（赤→オレンジ→緑点滅→緑点灯）

追加: タッチスクリーンディスプレイでの充電状態表示（充電率%、推定完了時間等）

要確認 充電ポートの位置と形状

情報不足:

  • 充電ポートの車両上の具体的な位置（左側面?右側面?）
  • 充電コネクタの種類（Type1? 独自規格?）
  • 充電ケーブルは車両付属か、別売りか
  • 充電中のディスプレイ表示のスクリーンショット
  • 急速充電（DC）対応の有無
追加 バッテリー温度管理

LFPバッテリー特有の温度管理に関する説明を追加:

  • 低温時（0℃以下）の充電性能低下
  • 高温時（35℃以上）の充電制限
  • バッテリーウォーマー機能の有無
▼ 4. 安全装置（シートベルト） 重要度: 低
書き換え シートベルトの種類

基本的な3点式シートベルトの説明は同じだが、以下を追加:

  • 台湾仕様: 助手席用シートベルト（2人乗り対応）
  • ISOFIXチャイルドシート装着時の注意事項（台湾仕様のみ）
要確認 日本仕様のシートベルト仕様

情報不足:

  • シートベルト警告灯の有無
  • シートベルトプリテンショナーの有無
  • 助手席（台湾仕様）のシートベルト固定点の位置
▼ 5. 操作装置 重要度: 高
追加 タッチスクリーンディスプレイ

全面的に新規作成が必要:

  • ディスプレイの画面構成とメニュー
  • 速度表示、バッテリー残量表示の見方
  • 航続距離の推定表示
  • エアコン操作方法
  • 走行モード選択（エコ/ノーマル等があれば）
  • 各種設定画面の操作方法
削除 アナログメーターの説明

以下のCOMS固有の説明を削除:

  • スピードメーター（針式）
  • バッテリー残量計（8目盛）
  • トリップメーター/オドメーターボタン
書き換え キースイッチ → スタートボタン
キースイッチ（LOCK/ACC/ON） → プッシュスタートボタン（キーレスエントリー?）

⚠ 要確認: Lean3のキー/スタートシステムの詳細仕様が不明

書き換え シフトレバー → シフト操作

COMSとLean3のシフト操作の違い:

物理的なシフトレバー（R/N/D） → ボタン式シフト操作パネル（要確認）
書き換え ハンドル操作範囲
通常のハンドル操作 → 半回転で旋回可能（約180度でフルロック）

※最小回転半径3.6mを実現する特殊なステアリング設定

追加 エアコン操作

CODSには無かったエアコンの操作説明を追加:

  • 冷房システムの操作方法
  • 温度調整（範囲と設定方法）
  • 風量調整
  • デフロスター機能
  • エアコン使用時の航続距離への影響
要確認 操作系の詳細仕様

情報が不足している項目:

  • スタートシステム: キーレス? スマートキー? 物理キー?
  • ドアロック: 集中ドアロックの有無と操作方法
  • パーキングブレーキ: 電動? 機械式? 位置は?
  • ワイパー・ウォッシャー: 操作方法と位置
  • ライト操作: 自動点灯機能の有無
  • 方向指示器: レバー式? ボタン式?
  • ホーン: ハンドルのどの位置?
▼ 6. 快適装備 重要度: 中

以下のセクションを全て削除:

  • ドアポケット（あれば）
  • カップホルダー（位置と数）
  • USB Type-C充電ポートの使用方法

台湾仕様のみ:

  • ISOFIX固定点の位置
  • 対応チャイルドシートの種類と重量制限
  • 取り付け方法
  • 使用時の注意事項
削除 オプション部品の大半

以下のCOMS専用オプションを削除:

  • キャンバスドア・リヤキャンバス
  • サンバイザー
  • サイドバイザー
  • ボディーカバー
  • アクセサリー電源ソケット（USB Type-Cに置き換え）

情報不足: Lean3に用意されているオプション品の詳細が不明

  • アルミホイール（カスタマイズオプション）
  • カラーバリエーション
  • 追加アクセサリー類

▼ 7. 運転操作 重要度: 高
追加 Active Lean Technology の運転方法

最重要の新規セクション:

  • 傾斜の原理: カーブ時に自動で車体が傾く仕組みの説明
  • 運転姿勢: 傾斜時も体はまっすぐに保つこと
  • ハンドル操作: 半回転で旋回可能、滑らかな操作を心がける
  • 速度と傾斜角: 速度が高いほど傾斜角が大きくなる（最大28度）
  • 低速時の挙動: 5km/h以下では傾斜機能が作動しない
  • 雨天時: 路面状況により傾斜角が制限される場合がある
  • 急な操作禁止: 傾斜システムの追従限界を超える操作は危険
書き換え 発進手順の変更

キースイッチ操作 → スタートボタン操作（要確認）

メーター確認 → タッチスクリーンディスプレイ確認

書き換え 航続距離表示と警告
バッテリー残量8目盛 → 2目盛で警告 → バッテリー残量% + 推定航続距離km表示

※警告タイミング（残量20%? 10km未満?）は要確認

書き換え 回生ブレーキの説明

CODSとLean3で基本は同じだが、以下を明確化:

  • 回生ブレーキの強度設定（エコモード等があれば）
  • 後輪インホイールモーターによる回生の特性
  • 満充電時は回生が制限されることの説明
追加 エアコン使用時の注意

エアコン使用による航続距離への影響を説明:

  • 冷房使用時: 航続距離が約○%減少（要データ）
  • 暖房使用時: 航続距離が約○%減少（要データ）
  • 推奨設定温度と節電方法
要確認 運転支援機能の有無

情報不足:

  • ABS（アンチロックブレーキシステム）の有無
  • トラクションコントロールの有無
  • ESC（横滑り防止装置）の有無
  • 坂道発進補助機能の有無
  • 後退時の警告音
  • パーキングセンサー
▼ 8. 寒冷時の取扱い 重要度: 中
追加 LFPバッテリーの低温特性

リチウムイオン電池の低温時の特性を追加:

  • 0℃以下での出力低下（航続距離が約○%減少）
  • -10℃以下での充電制限または禁止
  • バッテリーウォーマー機能の有無と使用方法
  • 走行前のバッテリー予熱推奨（あれば）
追加 ヒーター使用時の注意

台湾仕様のヒーターオプション、または日本仕様のヒーター機能について:

  • ヒーター使用時の電力消費
  • 航続距離への影響
  • 推奨設定温度

後2輪に装着 → 前2輪に装着（駆動輪は後1輪だが、操舵輪の前輪に装着推奨）

⚠ 要確認: Lean3のタイヤチェーン装着推奨位置

要確認 寒冷時の仕様詳細

情報不足:

  • 動作保証温度範囲（-○℃ ～ ○℃）
  • バッテリーウォーマー機能の有無
  • 寒冷地仕様の設定有無
  • スタッドレスタイヤの推奨銘柄
▼ 9. メンテナンス 重要度: 中
書き換え タイヤ仕様の変更

タイヤサイズ:

4輪とも同一サイズ → 前輪: 90/90 R14 / 後輪: 150/70 R14

空気圧:

前: 2.5kgf/cm² / 後: 3.0kgf/cm² → 前輪: ○○kPa / 後輪: ○○kPa（要確認）
書き換え ブレーキシステム
前輪ディスク、後輪ドラム → 前輪・後輪ともディスクブレーキ
追加 Active Lean Technologyのメンテナンス

傾斜システム関連の点検項目を追加:

  • 傾斜機構の作動確認（定期点検項目）
  • センサー類の清掃と点検
  • システム異常時の警告表示
  • ソフトウェアアップデートの有無と方法
削除 バッテリー関連の点検項目

鉛バッテリー特有の点検項目を削除:

  • バッテリー液量の点検（LFPは密閉型）
  • バッテリー端子の腐食点検（不要）
  • バッテリー個別の電圧測定（システムで管理）
書き換え 電球交換 → LED

全てのランプがLEDのため、電球交換の説明を大幅に簡略化:

  • LEDは基本的にユーザー交換不可
  • 点灯しない場合は販売店へ相談
  • LED交換が可能な箇所があれば、その手順を記載
要確認 メンテナンスデータ

情報不足:

  • 車両重量（車両重量/総重量）
  • 推奨タイヤ空気圧
  • ブレーキフルードの種類
  • ウォッシャー液容量
  • 定期点検の間隔（12ヶ月/24ヶ月? 走行距離基準?）
  • 消耗品の交換時期一覧
