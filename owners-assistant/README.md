# Lean3 OWNER'S ASSISTANT - モックアプリ

Lean3オーナー向けアシスタントアプリのプロトタイプ版です。C-APP MVP要件に基づいて、主要な機能とUIフローを実装しています。

## 📦 バージョン選択

このモックアプリには2つのバージョンがあります：

### V1 - MVP版（9月末納品）
- **対象**: 2026年9月末のLean3納車開始に必須のマスト要件のみ実装
- **エントリーポイント**: `version-select.html` → V1選択
- **含まれる機能**:
  - ✅ 仮ログイン認証
  - ✅ 初回オンボーディング（簡略版）
  - ✅ お知らせ（ルールベースのみ、OTA除外）
  - ✅ FAQ動的表示
  - ✅ チャット（履歴保存・ユーザー評価）
  - ✅ マニュアル閲覧（PDF・オフライン表示）
  - ✅ 警告灯一覧（静的、マニュアルリンクのみ）
- **除外された機能**:
  - ❌ ステータス・ゲーミフィケーション
  - ❌ ソフトウェア更新お知らせ（OTA）
  - ❌ 今日のおすすめ
  - ❌ 警告灯リアルタイム点灯状態取得

### V2 - フル機能版（Phase 2以降）
- **対象**: 将来的な拡張機能を含むフルバージョン
- **エントリーポイント**: `version-select.html` → V2選択、または `index.html`
- **含まれる機能**: V1の全機能 + Phase 2機能
  - ✅ ステータス・ゲーミフィケーション
  - ✅ 7ステップオンボーディング
  - ✅ OTA通知
  - ✅ 今日のおすすめ
  - ✅ 警告灯点灯状態・販売店誘導

## 📱 概要

このモックアプリは、2026年9月末のLean3納車開始に向けて開発されるC-APPの機能を視覚化したプロトタイプです。実際のバックエンド機能はなく、UIとナビゲーションフローのデモンストレーションを目的としています。

## 🎯 実装されている主要機能

### V1 MVP版

#### 1. 仮ログイン認証
- **ファイル**: `index-v1.html`
- 緑色のブランディング（V1専用デザイン）
- デモモードでの即座アクセス
- 簡易的なユーザー情報保存

#### 2. 車両選択
- **ファイル**: `vehicle-selection-v1.html`
- Lean3 2026年式のみ選択可能
- 複数車両管理はPhase 2で対応の説明付き

#### 3. メインアプリ（5タブ）
- **ファイル**: `app-v1.html`
- ボトムナビゲーション: ホーム、チャット、マニュアル、警告灯、通知

##### 🏠 ホームタブ
- 検索ボックス（チャットへのショートカット）
- お知らせカード（2件表示、OTA・今日のおすすめ除外）
- 車両画像・よくある質問（FAQ）

##### 💬 チャットタブ
- AIチャットボットとの会話UI
- 履歴保存・メッセージ削除機能
- 回答ごとのユーザー評価（👍/👎）
- 充電、航続距離、アクティブリーンに関する自動応答

##### 📖 マニュアルタブ
- マニュアルセクション一覧（外部manual.htmlへリンク）

##### ⚠️ 警告灯タブ
- 全警告灯の静的一覧表示
- 各警告灯からマニュアルへのリンク
- リアルタイム点灯状態取得機能なし（V1制限）

##### 🔔 通知タブ
- ルールベース通知の一覧表示
- OTA通知・今日のおすすめは除外

### V2 フル機能版

V1の全機能に加えて：

#### 追加機能
- **📊 ステータスタブ**: 知識レベル・進捗バー・実績バッジシステム
- **🔄 7ステップオンボーディング**: 詳細な初回ガイド
- **📡 OTA通知**: ソフトウェア更新完了のお知らせ
- **☀️ 今日のおすすめ**: 季節的なアドバイスと快適設定
- **⚠️ 警告灯リアルタイム**: 点灯状態の取得と販売店誘導フロー

## 🚀 使い方

### 起動方法

#### 方法1: ローカルサーバーを使用（推奨）

```bash
# LM_OM/owners-assistant ディレクトリで実行
python -m http.server 8080
```

ブラウザで以下のいずれかを開く：
- `http://localhost:8080/version-select.html` - バージョン選択画面（推奨）
- `http://localhost:8080/index-v1.html` - V1 MVP版に直接アクセス
- `http://localhost:8080/index.html` - V2フル機能版に直接アクセス

#### 方法2: 直接ファイルを開く

`version-select.html` をブラウザで直接開く（一部機能制限あり）

### デモフロー

#### V1 MVP版の場合

1. **バージョン選択**
   - `version-select.html` を開き、「V1 - MVP版」を選択

2. **ログイン画面** (`index-v1.html`)
   - 「デモモードで開く」ボタンをクリック
   - または任意のメールアドレス・パスワードを入力してサインイン

3. **車両選択** (`vehicle-selection-v1.html`)
   - Lean3 2026年モデルがデフォルトで選択済み
   - 「続ける」ボタンをクリック

4. **メインアプリ** (`app-v1.html`)
   - ホーム画面が表示されます
   - ボトムナビゲーション: ホーム、チャット、マニュアル、警告灯、通知（5タブ）

#### V2 フル機能版の場合

1. **バージョン選択**
   - `version-select.html` を開き、「V2 - フル機能版」を選択

2. **ログイン画面** (`index.html`)
   - 「デモモードで開く」ボタンをクリック

3. **車両選択** (`vehicle-selection.html`)
   - Lean3 2026年モデルがデフォルトで選択済み

4. **オンボーディング（初回のみ）**
   - 7ステップのはじめてガイド
   - 「はじめる」または「スキップ」でホームへ遷移

5. **メインアプリ** (`app.html`)
   - ホーム画面が表示されます
   - ボトムナビゲーション: ホーム、チャット、マニュアル、通知、ステータス（5タブ）

### シーン別体験（6種類）

UI上にデモ選択はなく、通常のアプリ操作から自然に体験できます。

| シーン | 体験の入り方 |
|--------|-------------|
| 納車直後 | 初回ログイン時に自動で「はじめてガイド」が表示 |
| 充電時 | チャットのクイック質問・FAQ・通知「充電のヒント」 |
| OTA後 | 通知「ソフトウェア更新が完了」→ ホームに変更点カード |
| 日常活用 | 通知「今日のおすすめ設定」→ ホームにおすすめカード |
| トラブル時 | 警告灯タブ（警告点灯2件）から各ケースの対処フローを開始 |
| 販売店連携 | ケース①：販売店共有→ロードアシスタンス / ケース②：販売店検索→入庫予約 |

## 📝 注意事項

1. **モック版の制限**
   - このバージョンはUIデモンストレーション目的です
   - 実際のデータ保存やバックエンド処理は行われません
   - チャットボットの応答は簡易的なキーワードマッチングです

2. **ブラウザ互換性**
   - モダンブラウザ（Chrome, Firefox, Safari, Edge）で動作確認済み
   - IE11は非対応

3. **データの永続化**
   - localStorageを使用した簡易的な保存
   - ブラウザのキャッシュクリアで削除されます
