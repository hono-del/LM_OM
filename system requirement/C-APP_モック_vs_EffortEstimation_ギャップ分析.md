**作成日:** 2026年6月8日  
**最終更新:** 2026年6月8日（モック改善反映）  
**比較元（機能リスト）:** `CMC NDG Next - C-App Effort Estimation (R-Edge).xlsx`（Sheet: Project_ndg v2.0）  
**比較対象（現行モック）:** `owners-assistant/`（C-APP UIモック）、`manual.html`（マニュアルビューア）、関連データファイル

---

## 1. 目的と前提

本ドキュメントは、Effort Estimation に記載された WBS 機能と、現時点の HTML/JS モックの差分を整理する。  
**過剰** = モックにあって Excel の MVP スコープにない、または実装がスコープを超えている／別用途のもの。**不足** = Excel（特に MVP）にあってモックにない、または UI のみで実体がないもの。

### モックの位置づけ

| 項目 | 内容 |
|------|------|
| 技術 | 静的 HTML + Vanilla JS、localStorage / sessionStorage |
| バックエンド | なし（AI・IDP・プッシュ・CMS・管理者パネル未接続） |
| 対象車種 | Lean3 のみ（2024/2025/2026 年式） |
| 主目的 | Lean3 向けシーン別体験のデモ・要件の視覚化 |

### 凡例

| 記号 | 意味 |
|------|------|
| ✅ | モックで主要 UI/フローが確認できる |
| 🔶 | 部分実装（見た目のみ・固定データ・簡易ロジック） |
| ❌ | 未実装 |
| ➕ | 過剰／モック独自（Excel MVP に明示なし、または Phase 先行） |

## 7. 結論と推奨アクション

### 結論

1. 現モックは **「Lean3 向けシーン体験デモ」** に加え、**Status・チャット履歴・出典付き回答・評価 UI・警告灯グリッド・ゲーミフィケーション** など、Effort Estimation MVP の**画面要件をかなりカバー**する段階に到達した。

3. **過剰の中心**は変わらず、**販売店予約・ロードアシスタンス・6 シナリオ演出・オンボーディング厚み・デモ用リセット**で、プレゼン向けには有効。
